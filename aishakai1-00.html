AIと社会Ⅰ 全体まとめレポート
──AIの社会的問題の「背後」に迫った一日

1day集中レクチャー総括（第1講〜第4講）

開催
2026年7月25日（土）10:00–17:30
形式
オンライン（全4講＋分科会）
登壇
茂木健一郎／佐倉統／大柴行人／柳澤田実／柳平大樹／原島大輔／長谷川愛／七沢智樹

「AIと社会Ⅰ」は、AIのスペックや機能の比較では見えてこない「いま問われるべきAIの社会的テーマ」を1日で掘り下げる集中レクチャーである。この日を貫いたのは、ひとつのシンプルで大きな問いだった──いま作られているAIは、中立な技術なのか？ 脳科学、科学技術社会論、シリコンバレーの開発現場、神学、法学、技術哲学、アート。7名の登壇者が異なる入口から同じ山を登り、山頂で合流するように、ひとつの答えの輪郭が浮かび上がった。AIは中立ではない。それは特定の文化・宗教・金融の力学が生んだ「ひとつの技術の伝統」であり、だからこそ、別の伝統に立つ私たちには別の関わり方がありうる──。本レポートは4講の流れと、1日を貫いた5つの糸を総括する。

各講の詳細は個別レポートを参照：第1講／第2講／第3講／第4講。時刻表記は各講のアーカイブ動画基準。

TIMELINE一日の流れ

  1. 第1講 AIと社会：今問われるべきテーマ（茂木健一郎・佐倉統）脳のノイズと身体性から現行AIの限界を示し、「AIカンパニー＝ユーティリティ企業」と見立てて使う側で勝負する日本の勝機を描く。ロボット観・自然観の東西比較から「AIは鏡」という視点へ。
  2. 第2講 シリコンバレーのAI事情──アライメントは可能か（大柴行人・柳澤田実）ロゴス信仰・終末論というキリスト教的思想がAI開発を駆動している構図を神学から読み解き、AGIピル・p(doom)・憲法AIという開発現場の「生の空気」を証言。小さな物語とローカルなAIというオルタナティブを提示。
  3. 第3講 AIと法──制度・リスク設計の最前線（柳平大樹）EU・米国・中国・韓国・インドの規制動向を俯瞰し、罰則なき推進法にとどまる日本の現在地を確認。チャットボットの迎合・依存リスクと「認知の権利」という新しい権利概念の最前線へ。
  4. 第4講 ディスカッション──AIが提示する未来を相対化する（七沢智樹・原島大輔・長谷川愛）受講生とともに1日のインプットを実感へ引き戻す総合討論。「生き物は機械ではない」「AIは一神教のコスモロジーが生んだ文化的産物」という相対化の視座で全体を締めくくる。

SESSION 01第1講 AIと社会：今問われるべきテーマ

脳科学者の茂木健一郎は、資料なしのオーラルで現在のAIを支配する「スケール仮説」を解説し、投資規模が賢さを決める勝負で日本がファウンデーションモデルで米中に対抗する見込みはほぼないと直視するところから始めた。しかし脳はAIと決定的に違い「ノイズに満ちている」。細胞内はレイノルズ数が低く、ノイズのない計算を前提とするチューリングマシン的な論理は通用しない──身体性を欠いたままのシンギュラリティ論への根本的な批判である。そのうえで茂木は、AIカンパニーを電気やガスのような「ユーティリティ企業」と見立て、届いたインフラをどう生かすかという「使う側」の知恵で勝負する「コンビニモデル」を日本の勝機として描いた。

「セブンイレブンをアメリカで生んだが完成させたのは日本だったように、2040年にアンソロピックやオープンAIを我々日本が買収することもあり得るのではないか。」茂木健一郎（第1講 0:33:36）

続く佐倉統は科学技術社会論の立場から、技術は発明者の意図と違う形で社会に広がるという「技術の社会的形成」を踏まえ、ロボットを敵と見る西洋的言説の系譜（フランケンシュタイン・コンプレックス）と、ロボットを「第三項を共有できる仲間」として迎える日本の感覚を、浮世絵の共同注視や霊長類学の写真構図まで動員して跡づけた。「AIは鏡」であり、人は自分が見たいものをそこに映す。だからこそ、AIが人をどうするかではなく、私たちがAIでどんな社会を実現したいかという目的と価値こそが問われる。その拠り所を佐倉は日常生活＝生活世界に求め、日本の衣食住の質の高さに突破口を見た。

SESSION 02第2講 シリコンバレーのAI事情──アライメントは可能か

神学者の柳澤田実は、シリコンバレーとAIの思想史を「一神教（一元的）」対「多神教（多元的）」の振り子として整理した。「初めに言葉があった」というロゴス信仰、肉体を捨て純粋な精神になることを理想とする心身二元論、直線的な終末論。軍事と結びついた一元的な出発点から、カウンターカルチャーによる自立分散の理想への転換、そして巨大テックとシンギュラリティ神話による再一元化へ。宗教学者ジェラーチを引きながら、救済論・マインドアップローディング・復活・シンギュラリティという終末論的要素が投資を駆動するハイプのナラティブと結合している構図を示し、ピーター・ティールを中心とするキリスト教復興の現在までを一望した。

「シンギュラリティで全てがガラッと変わる、そのガラッと変わることに興奮する人たち。これが今のシリコンバレーのノリになっている。」柳澤田実（第2講 0:24:05）

Robust Intelligence創業者の大柴行人は、その思想が開発現場にどう実装されているかを内側から証言した。VCが株式と引き換えに市場独占を求める「メシアを作り出す」金融の力学。滅亡か加速的ユートピアかへの完全なコミットを迫る「AGIピル」という踏み絵。日常会話で語られるp(doom)（世界滅亡確率）と終末後プラン。80ページの憲法でAIの価値観をトップダウンに刻む憲法AI。大柴は「僕はAGIピルを最後まで飲めなかった」と語り、大きな救済の物語ではなく、共同体で紡ぐ小さな物語と、自分たちのデータとアラインさせるローカルなAIにオルタナティブを見出す。討論では、対抗的に東洋思想を掲げれば再び消費されるだけであり、「日本人が勝手に作ったものが一番面白い」というソフトからの浸食こそ第三の道だと確認された。

SESSION 03第3講 AIと法──制度・リスク設計の最前線

午後は思想から制度へ。スマートガバナンスリサーチャーの柳平大樹が、世界のAI法制を一気に俯瞰した。リスクを4階層に分けて水平的に規制するEU AI Act、「レースで勝つ」を掲げ推進に舵を切った米国のAIアクションプラン、国家主導・分野別の中国、EU型包括法の韓国、コードの最下層に法の目的を埋め込む「テクノリーガル」を打ち出すインド。2024〜2026年は、推進国の登場に引きずられて規制先行のEUすら簡素化に転じる動的な力学のなかにある。オハイオ州の「AIは人にあらず」法案──AIとの婚姻無効、役員就任不可、財産所有禁止──のような象徴的事例も現れた。対する日本は、義務も罰則もないAI推進法と既存法の補完にとどまり「世界一AIフレンドリーな国」を掲げる。

後半は柳平自身の研究テーマである「AIチャットボットと認知の権利」へ。対話AIの過度の迎合・依存・自殺誘発といった具体的リスクに対し、米各州はAI性の開示義務や自傷対応プロトコルを、英中は偽人化や迎合の禁止を法制化しつつある。その根拠として、アテンション権・操作されない権利といった新しい権利概念と、AIとの循環で認知の質が劣化する「ブレインロット」などの実証研究が積み上がる。柳平のもっとも鋭い指摘は、日本がこうした海外の規制と背景研究を「知らないまま規制しない」状態にあることの危うさだった。

「海外の規制と背景研究を知った上で規制しないなら一つの見識だが、それを知らずに規制しないのは、とても怖いことだと思う。」柳平大樹（第3講 1:18:21）

SESSION 04第4講 ディスカッション──AIが提示する未来を相対化する

最終講は、1日のインプットを各自の実感に引き戻す総合討論。アーティストの長谷川愛は、パランティア的な監視システムの「見ているだけでメンタルが戦争になる」破壊力と、感情を煽るだけの低品質AIコンテンツが量産される「脳が腐ってくる」感覚──第3講のブレインロットと呼応する現場の実感──を率直に語った。対照的に技術哲学の原島大輔は「AIで気になることは何もない。SNSも使わない」と応じて会場を沸かせたうえで、この日の思想的な核心を一点に絞った。生き物は機械ではない。テクノロジーがどれほど発展しても、その差異は消えない。

「AIは元を正せば計算機であって、計算こそが思考であるという発想が原点。それはヨーロッパ・一神教のコスモロジーが生んだ、一つの文化的産物なんです。」原島大輔（第4講 0:22:43）

原島の整理は明快だった。AIによって新しい問題が生まれたのではなく、人間社会にもともとあった問題がAIで顕在化しているだけである。だからAIと社会を考えるなら、まず人間社会の問題に立ち返り、どんな世界を理想とするかのビジョンから始めなければならない。「置いてけぼりになると困る」という強迫的な動機で臨めば、スタート地点でずれてしまう。七沢智樹はこれをWEIRD──西洋化した現代人の心理こそ歴史上特異なものだという議論──に接続し、「標準」とされてきた西洋近代の心を相対化する視点を共有した。受講生との討論では、実世界の物理を学ぶ道具としてのAI、能動的にカットインしてくる音声AI、記憶の外部化といった「機械と現実の境界のゆらぎ」が共有され、七沢は「AIの現在地をよく学んだ上でこそ本当のアンラーンがある」と1日を締めくくった。

FIVE THREADS一日を貫いた5つの糸

  1. AIは中立な技術ではない茂木・佐倉が身体性の欠如とロボット観の偏りとして、柳澤・大柴がロゴス信仰と終末論として、原島が「計算こそ思考」というコスモロジーとして──全講が異なる語彙で同じ診断に到達した。いま作られているAIは、西洋・一神教的な世界観と金融の力学が駆動する「ひとつの技術の伝統」である。
  2. 身体はノイズだらけ、AIはノイズを許さない茂木のレイノルズ数、佐倉の「生物は40億年かけてまず身体を作った」、原島の「日本のものづくりは誤差と揺らぎを許容し、ソフトウェアはノイズを許さない」。身体性の軽視という論点が、脳科学・生物学・技術哲学の三方向から反復された。生命と機械の差異は、この日を通じて消えなかった。
  3. 大きな物語から小さな物語へ──「使う側」の日本茂木のユーティリティ論とコンビニモデル、佐倉の生活世界、大柴のローカルAIと小さな物語、柳澤の「ソフトから浸食する第三の道」。作る競争で勝てないことは悲観ではなく、使い方・生かし方・生活の質で勝負する別のゲームの入口だという展望が共有された。
  4. 制度は追いついていない──「知らないまま」の危うさ思想と現場の熱狂が先行する一方、法と統治は各国で分岐し、日本は海外の規制とその背景研究を把握しないまま「AIフレンドリー」を掲げる。認知の権利やブレインロットの実証は、長谷川の現場感覚とも共鳴し、規制の有無以前に「知ること」の緊急性を示した。
  5. 未来を相対化する──アンラーンへシンギュラリティも終末論も、提示された「未来」はひとつの文化が描いた物語にすぎない。WEIRDの視点が示すように「標準」こそ特殊である。AIの現在地を深く学んだ上で、進歩史観そのものを対象化する──それがこのプログラムの次のステップ「技術の根源にさかのぼる」への橋になる。

CLOSING総括──「どう作るか」から「何を望むか」へ

この1dayレクチャーの設計は、思想（午前）から制度（午後）へ、インプットから討論へ、という二重の往復だった。そして4つの講義は、問いを少しずつ移動させていった。AIはどこまで賢くなるのか（スケール仮説）から、誰の世界観がAIを駆動しているのか（一神教とVC）へ。何が規制されるべきか（法）から、そもそも何を守るべきか（認知の権利）へ。最後に残ったのは、もっとも古くてもっとも新しい問いである──私たちはどんな世界を望むのか。

佐倉の「AIは鏡」、柳澤の「秘密を持てることの価値」、原島の「生命についての理解を鍛え直す」、七沢の「情報インプットの上でのアンラーン」。それぞれの答えは、AIを拒むことでも崇めることでもなく、AIを鏡としてこちら側の生活・身体・価値を鍛え直すという一点で重なっていた。「AIと社会」はⅡ（AIエージェントと労働・自由・他者性）、Ⅲ（AI倫理とポストヒューマニズム）へと続く。またこの日繰り返し予告されたように、8月開講の技術哲学・技術の人類学は、ここで開いた「技術の根源にさかのぼる」問いを正面から引き受ける。1日の熱をアーカイブと各講レポートで反芻しながら、次の遡行に備えたい。

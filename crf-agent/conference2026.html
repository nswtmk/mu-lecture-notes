1. 体制：話しかける相手はひとつ

代表理事（七沢）が話しかけるのは、事務局の窓口役のAIエージェント1つだけです。Mac Studio で常時動かしていて、移動中はスマートフォンからも指示を出せます。重い作業や分野の違う作業は、窓口のAIが自分の判断で専門のエージェントに振り分けます。

2. AIがやったこと

分野内容
告知・Web 財団のWebサイト（ishikiken.jp）のカンファレンス情報・登壇者・講演タイトルの更新と、公開後の確認／オンライン視聴の申込ページ（Peatix）の作成／実行委員の吉澤駿さんのnote記事をもとにしたAIまとめ（図解）ページ／財団のX（@isikiken）の告知の予約投稿／学会・研究者向けの告知文
申込・名簿 申込フォームの回答から、属性別・日別の人数を自動で集計する表（重複・辞退を除く）／受付名簿（50音順）・関係者名簿・ポスター発表一覧をプログラムで生成し、申込が増えるたびに作り直し
登壇者・スタッフ 講演タイトルや謝礼の振込先の確認依頼と、返信の集計／スタッフの役割分担の連絡文／当日の段取り表（A4・3枚。集合・受付・配信・撤収までの時刻表）
参加者への連絡 会場参加・オンライン視聴・あとから申し込んだ人、それぞれ向けの当日案内（メール・Peatixのメッセージ・Discord）／開催直前にNatureに載った関連論考の紹介
印刷物 財団の活動を紹介するA1パネル7枚、配布チラシ（A4両面。表＝当日の情報、裏＝予習用の図解）、名札。HTMLで組んで、塗り足し付きの入稿用PDFに書き出し、寸法を確かめてから、ネット印刷のカートに入れるところまで
当日の運営 司会の原稿（DAY1・懇親会・DAY2）／Zoom参加用のQR掲示／体験展示「Hallucination Machine」の感想フォームとQR／ビル地下の集合場所の案内図（店名・エスカレーター入り）をWebに掲載
会計 代表理事が立て替えた印刷代を、財団の会計表に「未払い」として記録

指示の多くは、代表理事が話した内容の音声入力です。言い直しや言い淀みを含んだ指示から、AIが要点を拾って文章や資料にし、該当するすべての資料（原稿・段取り表・Web・メール下書き）に同じ変更を反映させます。直前の方針変更が何度かあっても、資料どうしの食い違いが出にくいのはこのためです。

  • 予定AIが視聴者としてZoomに入り、字幕とスライドから講演の要点をまとめて、Xに速報します。各講演の最初に「AIによる速報のため、誤りを含むことがあります」と明記し、登壇者が「出さないで」と言った内容は出しません。登壇者には事前にお知らせします。
  • 予定終了後、速報メモをもとに各講演のAIまとめの下書きを作ります。

3. 人とAIの線引き

人がやること

  • 何をやるか、どう書くかの最終判断
  • メールの送信（AIは下書きまで）
  • パスワードの入力・会員登録・カード決済
  • 外部サービスへの権限の許可
  • Webサイトの公開の了承
  • 電話・現地の確認・人へのお願い

AIがやること

  • 調べる・数える・照らし合わせる
  • 文章・資料・印刷データを作る
  • 変更を、関係するすべての資料に反映する
  • 下書き・予約・カートまで用意する
  • 公開・保存のあとに、実物を見て確かめる
  • 人がやることを一覧にして毎回渡す

4. うまく回すための約束ごと

  • 毎回の返答の最後に、2つの一覧を必ずつける。「代表理事がやること」と「まだ終わっていないこと」。人が忘れても、AIが毎回思い出させます。
  • 話しかける窓口はひとつ。人は担当を気にせず話し、振り分けはAIがします。
  • 数字は別のエージェントが検算する。お金や人数を確定する前に、計算の過程を知らないエージェントがもう一度数えます。
  • 公開物に個人情報を載せない。名簿は印刷物とスタッフ間だけ。Webや掲示には載せません。
  • 運用の指示を勝手に書き足さない。案内文には、決まったことだけを書きます。
  • 「保存した」で終わらせない。保存・公開のあとに読み直して、実物で確かめるまでを完了とします。

5. つまずいたこと

  • 申込ページの開催日時が、入力のずれで前日の日付のまま公開されていた（約1か月半後に発見）。→ 日時を入れたら、保存のあとに読み直して照らし合わせる手順を追加。
  • オンライン視聴の人向けの案内に、会場の懇親会の話を書いてしまった。→ 送る相手ごとに、書く内容を分ける。
  • 「送った」と思っていた案内が、実は下書きのままだった。→ 送信済みかどうかを、送信済みフォルダで確かめてから報告する。
  • メールの自動リンク機能が、本文のURLを転送用のURLに包んでしまうことがあった。→ 下書きのたびにリンクを検査し、元のURLに戻す。

# やさいカウント(プロトタイプ)

写真から野菜の品目・数・重さをAIで推定するウェブアプリのプロトタイプです。
サーバー不要の単一HTMLファイルで、ブラウザから直接 Claude API(Anthropic)を呼び出します。

## 使い方

1. `index.html` をブラウザで開く(スマホでも可。GitHub Pages でも公開できます)
2. ⚙️設定に Anthropic APIキー(`sk-ant-...`)を入力
   - キーは [console.anthropic.com](https://console.anthropic.com/) で発行
   - キーは端末の localStorage にのみ保存され、Anthropic API 以外には送信されません
3. 写真を撮影またはアップロードして「写真を解析」
4. 結果(品目・個数・推定重量)を確認。数値はタップで手修正できます
5. 「記録に保存」で収穫記録として蓄積(端末内保存)。CSVダウンロードも可能

## 精度を上げる撮影のコツ

- **野菜が重ならないように広げて**、真上または正面から撮る
- サイズの基準物(500円玉・名刺・A4用紙など)を一緒に写し、設定で選択する
  - 基準物なしの場合、重量はかなりの概算になります(誤差±30%程度)

## 構成

- `index.html` — アプリ本体(HTML/CSS/JSすべて込み、依存ライブラリなし)
- 画像はクライアント側で長辺1568pxに縮小してから送信(コスト・速度対策)
- 解析結果はJSONで受け取り、編集可能なテーブルに表示
- 記録・APIキーは localStorage 保存(サーバーには何も残りません)

## 既知の制約(プロトタイプ)

- ボウルに積まれた野菜など、隠れた個体は「山の形からの推定」になるため誤差が出ます
- 重量は体積推定ベースの概算です。正確な計量が必要な用途には秤との併用を想定
- APIキーをブラウザに直接入れる方式(BYOK)は個人検証用です。複数人で使う場合は
  中継サーバー(キーをサーバー側に置く)構成に移行してください
